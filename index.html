PRIVACY 🔒

These controls represent the direction for Novie's secure sharing system.

My sharing defaults

New personal information stays private.
Ask before sharing
Novie asks before sharing personal insights.

Sharing should be specific

💗 Partner: “I am having a harder day today and could use some extra patience.”
👩‍👧 Family: “I would love a check-in today.”
👯 Friend: “Want to do something fun this weekend?”

The future Novie system will separate these shareable insights from the private information used to generate them.


🔐 Security roadmap

This browser MVP is for testing the experience. Before Novie stores real sensitive information for multiple users, we will build proper authentication, encrypted data storage, permission rules, account controls and secure sharing.
